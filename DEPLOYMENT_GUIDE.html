1

เตรียมบัญชี Google กับสิทธิ์ที่ต้องมี

~5 นาที
  • ใช้บัญชี Google ขององค์กร (โดเมนเดียวกับแม่แบบ) เพื่อให้ webapp.access=DOMAIN ทำงานถูก
  • ขอสิทธิ์ Editor บน Spreadsheet ใหม่ + เข้า Apps Script Editor ได้
  • ยืนยันรายชื่อ: Owner (ผู้ดูแลหลัก) / Editor (ผู้ช่วย) / Viewer (เจ้าหน้าที่ตรวจ)
💡 แนะนำ ตั้งบัญชี Service Owner ร่วมกัน (เช่น lab-admin@org.ac.th) เพื่อไม่ให้เฉพาะบุคคลเดียวค้นหาไฟล์
✅ Checkpoint: ผู้ดูแล + สิทธิ์พร้อม
2

สร้าง Google Sheet ใหม่

~3 นาที
  1. ไปที่ sheets.google.com → Blank
  2. ตั้งชื่อ เช่น CE-FAIR-SCI-B02
  3. เก็บ Spreadsheet ID จาก URL (ระหว่าง /d/ กับ /edit)
✅ Checkpoint: Spreadsheet พร้อม + ID จดไว้
3

เปิด Apps Script เตรียมโปรเจกต์

~3 นาที
  1. เปิด Sheet ใหม่ → Extensions → Apps Script
  2. เปลี่ยนชื่อโปรเจกต์ เช่น CE-FAIR-B02
  3. สร้างไฟล์เปรียง: Code.gs, Index.html, JavaScript.html, Stylesheet.html, ReviewModal.html
💡 ถ้าใช้ clasp ก็ clone แล้วปรับ scriptId ไปที่โปรเจกต์ใหม่
4

คัดลอกไฟล์ซอร์สทั้ง 6 ไฟล์

~10 นาที
ไฟล์หน้าที่จำเป็นไหม
Code.gsBackend, schema, token securityบังคับ
Index.htmlContainer 2 แท็บ + includeบังคับ
JavaScript.htmlFrontend Vue, cache, componentsบังคับ
Stylesheet.htmlธีม + responsiveบังคับ
ReviewModal.htmlModal ดูรายละเอียด/อนุมัติบังคับ
appsscript.jsonRuntime, Web App, Scopesบังคับ
validate.jsตรวจก่อน deployแนะนำ
🧾 ใช้ clasp: ตั้ง .claspignore ให้ push เฉพาะ 6 ไฟล์นี้
⛔ ก่อนนำเข้าตรวจให้แน่ใจ — อย่าให้มี secret/API key หลงค้างอยู่ในโค้ด
5

ตั้ง manifest / OAuth Scopes

~3 นาที
{
  "timeZone": "Asia/Bangkok",
  "dependencies": {"enabledAdvanced": []},
  "executionApi": {"version": "V8"},
  "oauthScopes": [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/calendar",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/userinfo.email",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/script.scriptapp",
    "https://www.googleapis.com/auth/script.send_mail"
  ],
  "webapp": {"executeAs": "USER_ACCESSING", "access": "DOMAIN"}
}
💡 ทุกครั้งที่ปรับ scopes ให้ deploy test → reconsent ก่อน production
6

สร้างฐานข้อมูลด้วย initDatabase()

~5 นาที
  1. Apps Script Editor → ฟังก์ชัน initDatabase → Run
  2. สร้างชีต 10 แท็บ: Requests, Users, Rooms, Settings, RoomClosures, Advisor, DivisionStaff, LabHead, Admin, Logs
  3. เติม metadata columns ต่อท้าย Requests (12 คอลัมน์ token metadata)
  4. ตรวจผล log ใน Logs sheet
✅ Checkpoint: 10 ชีต + Requests ครบ 61 คอลัมน์
7

ใส่ข้อมูลพื้นฐาน: Rooms, Advisor, DivisionStaff, LabHead, Admin

~15 นาที

Rooms

  • ใส่ RoomID, ชื่อ, อาคาร, ชั้น, ความจุ, facilities, อีเมล Lab Head, image URL, status

Advisor

  • อีเมลอาจารย์ที่ปรึกษา (ขั้น 1)

DivisionStaff / LabHead / Admin

  • อีเมลผู้อนุมัติแต่ละขั้น และสิทธิ์จาก Dashboard
💡 คัดลอกจาก Sheet ตัวอย่างของแม่แบบเดิมได้เลย แล้วปรับรายชื่อตามหน่วยงานใหม่
8

ตั้ง Script Properties (ORG_API_KEY, BIOMETRIC_*)

~5 นาที

Apps Script Editor → Project Settings → Script Properties → Add property:

Keyความหมายหมายเหตุ
ORG_API_KEYKKU Gen AI Keyใช้ AI/Chatbot เท่านั้น
BIOMETRIC_API_URLWebhook URL สแกน Biometricถ้ามีการเชื่อมต่อ
BIOMETRIC_WEBHOOK_SECRETshared secret Webhookจำเป็นสำหรับ Webhook
⛔ ห้ามใส่ค่าจริงในซอร์ส/เอกสาร — เก็บ Script Properties เท่านั้น
9

ปรับ Settings (อีเมล, prefix, retention)

~5 นาที
  • ADMIN_EMAIL → อีเมล Admin ใหม่ของหน่วยงาน
  • HEAD_OF_CIVIL_ENG_EMAIL → หัวหน้าสาขาใหม่
  • REQUEST_ID_PREFIX → เช่น B02- กันรหัสข้ามอาคาร
  • DATA_RETENTION_MONTHS → เช่น 12

ติดตั้ง Trigger รายวัน

~3 นาที

รัน setupDailyTriggers() → ผล:

  • updateExpiredRequests — ทุกวัน 01:00
  • sendPendingApprovalReminders — ทุกวัน 08:00
  • applyDataRetentionPolicy — ทุกวัน 02:00
✅ Checkpoint: ฟังก์ชันตอบ {success:true}
11

รัน validation ก่อน Deploy

~2 นาที (ถ้าใช้ clasp/Git)
node validate.js
# หรือ
npm run validate

ตรวจ: ไฟล์ครบ, syntax OK, webapp.access=DOMAIN, ไม่มี secret/ต้องห้าม pattern, Q&A=50, components, functions, brace balance, token headers

✅ Checkpoint: แสดง ALL CHECKS PASSED (exit 0)
12

Deploy เวอร์ชันทดสอบ (Test Web App)

~5 นาที
  1. Apps Script → Deploy → New deployment → Web app
  2. Execute as: User accessing / Access: Anyone within domain
  3. คัดลอก Web App URL ไปใช้ทดลองก่อน
💡 อย่า deploy production ก่อนทดสอบเสมอ
13

OAuth Consent + Smoke Test ครบทุก service

อย่า deploy production ก่อนครบ
  • ☐ Consent screen แสดง scope ตาม manifest
  • ☐ ส่งอีเมล submit สำเร็จ (Logs Email = Success)
  • ☐ Calendar: Biometric Event สร้างแล้ว
  • ☐ Drive upload ได้ (whitelist, <5MB) และ reject mime อื่น
  • ☐ Webhook พร้อมส่ง (ถ้าตั้ง secret)
  • ☐ Execution logs: ไม่มี ERROR
14

Deploy Production + จด Deployment ID / Git tag

~5 นาที
  • Deploy → New deployment (production)
  • จด deploymentId / Web App URL
  • ถ้าใช้ Git: commit → git tag v1.0-bXX
  • แจ้ง maintainers ให้ backup revision ไว้
15

บำรงรักษาประจำ: Backup, ตรวจสิทธิ์, ความปลอดภัย

weekly/monthly/annual
  • Backup Sheet — ทุกสัปดาห์ (manual copy หรือ trigger DriveApp.makeCopy())
  • ทบทวนสิทธิ์ Admin — annual: ตัด Admin/DivisionStaff ที่ลาออก + rotate WEBHOOK_SECRET
  • ตรว Logs — ทุกสัปดาห์ ดูผล retention job ทำงานครบ
